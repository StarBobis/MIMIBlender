# 权重检测与优化

## 功能定位

Mod 制作流程里，权重传递（Weight Transfer）之后、导出 Mod 之前的那一段。
把游戏原模型或参考模型的顶点权重传给自制网格后，传递质量往往没人检查：

- **接缝**：平滑表面上的两个相邻顶点各自绑死在不同骨骼上，中间没有任何
  过渡骨骼，形变时蒙皮会硬折、撕裂或穿模。
- **孤立权重簇**：顶点组在远离主体的一小块区域上还有残留权重，游戏里表现为
  局部抖动、异常位移，而且通常藏在被遮挡的角落，肉眼很难先发现。

本功能只读写顶点组权重，不改拓扑、材质、法线、UV 和形态键，可以放心在
成品 Mod 网格上运行。

## 面板位置

3D 视图侧栏 `MIMITools` → **Weight Processing Panel**（默认折叠）。
面板位于 Model Processing 下方、Merged Sculpt 上方。

## 三个按钮

### Detect Weight Issues（检测权重问题）

扫描所有选中网格，把报告写到面板的 Last Report 区域，并把出问题的顶点选中，
进入编辑模式即可看到具体位置。再次点击会覆盖上一次的位置标记；检测不会修改
任何权重。

### Smooth Detected Seams（平滑检测到的接缝）

先做一次检测，只对检测到的接缝两端及其一圈邻居做拉普拉斯式混合，让权重从
“左一块右一块”变成连续渐变。非目标顶点的权重不改动。每轮混合后重新归一化。

### Clean Weights（清理权重）

移除低于阈值的微小权重、把每顶点影响数截到上限、再做归一化。如果某顶点的
所有权重都低于阈值，会保留其中最大的一个，避免顶点失去绑定而在绑定姿态里
僵死。

## 参数

| 参数 | 默认 | 语义 |
|---|---|---|
| Seam Threshold | 1.0 | 相邻顶点权重差的 L1 距离达到多少才算可疑接缝。两个顶点分别绑死在不同单骨骼上时差值为 2.0；正常渐变带通常远小于 1.0。 |
| Smooth Angle | 60° | 两个面法线夹角大于该值视为几何硬边，接缝检查跳过。调大 = 更多折角被当作“平滑”参与检测（更严格）；调小 = 更多折角被豁免（更宽松）。 |
| Min Cluster Size | 8 | 顶点组的连通分量小于该顶点数才报为孤立簇。 |
| Cluster Weight | 0.05 | 顶点权重高于该值才算该顶点组“存在”，用于连通分量统计。 |
| Iterations / Strength | 3 / 0.5 | 平滑轮数，以及每轮混入邻接平均值的比例。 |
| Min Weight | 0.01 | 小于该值的权重被 Clean Weights 移除。 |
| Max Influences | 4 | 每顶点最多保留的骨骼数。游戏导出只保留四个影响，超过会被静默截断。 |

## 检测判据

### 接缝

只检查“平滑、同材质”的内部边（恰好被两个面共享）：

1. 边的两个端点权重差的 L1 距离 ≥ Seam Threshold；
2. 两个端点的正权重组**没有交集**——即没有任何一根骨骼同时影响两侧，中间
   没有任何过渡；
3. 不是开放边界边、不是几何硬边（法线夹角超过 Smooth Angle）、两侧面材质相同。

第 2 条是关键：正常手腕处即使两侧权重差很大，也会共享“手”和“臂”两根骨骼，
不会误报；传递失败造成的块状区域则完全没有共享骨骼。

### 孤立权重簇

对每个顶点组求连通分量。只有一个合法大区域时属于正常；有两个以上大区域时也
正常（例如裙子前片和后片）；只有**小于 Min Cluster Size 且组内还存在主区域**
的小分量才报为孤立簇。

### 逐顶点检查

- 零权重顶点（导出后不跟随骨骼）
- 影响数超过 Max Influences（导出截断）
- 权重和偏离 1（未归一化）
- 低于 Min Weight 的微小权重（仅计数提示，不算问题）

## 已知限制（使用前请阅读）

1. **孤立簇可能误报独立配件**。帽檐、眼镜、耳环这类独立小部件如果绑的是身体
   同一根骨骼，会因为“该骨骼在身体上已有大区域 + 配件是个小分量”而被报为
   孤立簇。报告只给数量和大小，需要用户自己判断。
2. **低模正常硬切也会被报**。两圈顶点的圆柱手腕直接 A/B 硬切，会报 8 条接缝。
   这确实是形变时会折断的地方，报告是合理的，但用户可能认为是“正常模型”。
3. **锁定顶点组也会被修改**。Blender 的 `lock_weight` 只拦 UI 手动编辑，Python
   API 照样写入。检测按钮不碰权重；平滑和清理会修改锁定组，执行时会弹警告。
4. **只按拓扑连接判断邻接**。空间上紧贴但拓扑分离的两块网格互不影响，因此
   跨网格岛的权重跳变不会被接缝检查发现（这是有意为之，避免把独立部件算成接缝）。
5. **非流形边会被跳过**。三个或更多面共享的边无法判定边界性质，检测直接忽略。
6. **标记问题顶点会清空原有顶点选择**，并重置为只选中问题顶点。
7. 多对象、大量问题时报告面板最多显示 20 行，其余行数折叠提示。
8. 面板参数是场景级自定义属性，会随 `.blend` 保存；打开别人保存的工程会沿用
   其中的阈值设置。实测确认过（写入 0.75 保存后重新打开仍为 0.75）。

实测数据（Blender 5.2.0 LTS，factory startup）：

| 样本 | 结果 |
|---|---|
| 共面两四边形、共享边两侧纯 A / 纯 B | 1 条接缝，2 个问题顶点 |
| 共面两四边形、共享边两侧含混合权重 | 0 条接缝 |
| 90° 折角 + 权重突变 | 0 条接缝（几何豁免） |
| 45° 折角 + 权重突变 | Smooth Angle 60° 时报 1 条，44° 时豁免为 0 条 |
| 两个材质相邻 + 权重突变 | 0 条接缝（材质豁免） |
| 25 顶点主区域 + 3 顶点远处孤岛 | 1 个孤立簇，size 3 / main 25 |
| 两个 25 顶点分量 | 0 个孤立簇 |
| 8 段两圈圆柱、上下两圈 A/B 硬切 | 8 条接缝 |
| 10000 顶点 / 19800 边网格检测 | 0.10–0.23 秒 |
| 20 轮强度 1.0 平滑 | 权重和偏差 3e-8，无负权重 |
| 连续清理两次 | 第一次 1 个顶点变化，第二次 0（幂等） |

性能说明：检测耗时随顶点数近似线性，十万顶点网格预计 1–3 秒，属于用户主动
点击一次的量级。平滑只写检测到的目标顶点，清理只写真正发生变化的顶点，耗时
取决于问题数量而非网格大小。
