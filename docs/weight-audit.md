# 权重检测与优化

## 功能定位

Mod 制作流程里，权重传递（Weight Transfer）之后、导出 Mod 之前的那一段。
把游戏原模型或参考模型的顶点权重传给自制网格后，传递质量往往没人检查：

- **接缝**：平滑表面上的两个相邻顶点各自绑死在不同骨骼上，中间没有任何
  过渡骨骼，形变时蒙皮会硬折、撕裂或穿模。
- **孤立权重簇**：顶点组在远离主体的一小块区域上还有残留权重，游戏里表现为
  局部抖动、异常位移，而且通常藏在被遮挡的角落，肉眼很难先发现。

本功能只读写顶点组权重，不改拓扑、材质、法线、UV 和形态键，可以放心在
成品 Mod 网格上运行。

## 面板位置

3D 视图侧栏 `MIMITools` → **Weight Processing Panel**（默认折叠）。
面板位于 Model Processing 下方、Merged Sculpt 上方。

## 三个按钮

### Detect Weight Issues（检测权重问题）

扫描所有选中网格，把报告写到面板的 Last Report 区域，并把出问题的顶点选中，
进入编辑模式即可看到具体位置。每次点击都会重置标记：上一次的顶点选择会被清空，
再按当前结果重新选中（本次没有问题就保持全不选）。关闭 Mark Issues in Viewport
开关后不会重画标记，也不会清空上一次的标记。检测不会修改任何权重。

### Smooth Detected Seams（平滑检测到的接缝）

先做一次检测，只对检测到的接缝两端及其一圈邻居做拉普拉斯式混合，让权重从
“左一块右一块”变成连续渐变。非目标顶点的权重不改动。每轮混合后重新归一化。

### Clean Weights（清理权重）

移除低于阈值的微小权重、把每顶点影响数截到上限、再做归一化。如果某顶点的
所有权重都低于阈值，会保留其中最大的一个，避免顶点失去绑定而在绑定姿态里
僵死。

清理用的下界是 `max(Min Weight × (1 + 1e-6), 2e-6)`：检测读入时忽略 ≤1e-6 的
权重，写入更小的权重会让下一次读取看不到它、可见权重和漂移；而 float32 存储
加再次归一化又可能把边界权重挪动约一个相对 epsilon。下界同时留出这两层余量，
所以每次写出的权重都大于读层阈值，连续点击两次是幂等的（包括 float32 存储
导致的阈值边界）。平滑写回前也做同样的可见性剪枝与归一化。

## 参数

| 参数 | 默认 | 语义 |
|---|---|---|
| Seam Threshold | 1.0 | 相邻顶点权重差的 L1 距离达到多少才算可疑接缝。两个顶点分别绑死在不同单骨骼上时差值为 2.0；正常渐变带通常远小于 1.0。 |
| Smooth Angle | 60° | 两个面法线夹角大于该值视为几何硬边，接缝检查跳过。调大 = 更多折角被当作“平滑”参与检测（更严格）；调小 = 更多折角被豁免（更宽松）。 |
| Min Cluster Size | 8 | 顶点组的连通分量的顶点数**小于**该值才报为孤立簇。注意这是绝对大小：把它调到比某个非最大分量还大时，那个分量也会被报（最大分量永远是主区域，不参与上报）。 |
| Cluster Weight | 0.05 | 顶点权重大于或等于该值才算该顶点组“存在”（等于阈值也算），用于连通分量统计。 |
| Iterations / Strength | 3 / 0.5 | 平滑轮数，以及每轮混入邻接平均值的比例。 |
| Min Weight | 0.01 | 小于该值的权重被 Clean Weights 移除。实现下界为 `max(Min Weight × (1 + 1e-6), 2e-6)`，因此略高于阈值、但归一化后会掉到阈值以下的值也会被移除，不会留到下一次清理。 |
| Max Influences | 4 | 每顶点最多保留的骨骼数。MIMIBlender 的权重导出按目标预设的 BLENDWEIGHT 元素布局输出：多数预设只有 4 个影响，WWMI 的运行时布局可以是 8，YYSLS 还有 8 通道扩展路径。**4 是与多数预设兼容的保守值**；8 通道预设可以调到 8。 |

## 检测判据

### 接缝

只检查“平滑、同材质”的内部边（恰好被两个面共享）：

1. 边的两个端点权重差的 L1 距离 ≥ Seam Threshold；
2. 两个端点的正权重组**没有交集**——即没有任何一根骨骼同时影响两侧，中间
   没有任何过渡；
3. 不是开放边界边、不是几何硬边（法线夹角超过 Smooth Angle）、两侧面材质相同。

第 2 条是关键：正常手腕处即使两侧权重差很大，也会共享“手”和“臂”两根骨骼，
不会误报；传递失败造成的块状区域则完全没有共享骨骼。共享权重必须大于
`POSITIVE_WEIGHT_EPSILON`（1e-4）才被视为过渡骨骼；两侧只共享 ≤1e-4 的权重时
**仍会被报为接缝**（这是误报边界，不是漏报）。

适用边界（以下情况检测直接跳过，属于有意为之的漏报）：

- 只检查**恰好被两个面共享**的内部边；wire 边、单面开放边界、三个及以上面
  共享的非流形边都不参与。
- 面法线夹角使用**网格局部空间**，不是世界空间；物体非均匀缩放时两者不同。
- 夹角恰好等于 Smooth Angle 时由 float32 精度决定豁免与否，临界值不稳定。
- 零面积退化面的法线为零向量，`dot = 0 < cos(Smooth Angle)`，会被当成硬边
  豁免；绕序翻转导致相邻面法线反向（`dot ≈ -1`）同理。这两种网格本身异常
  时接缝会漏报。

### 孤立权重簇

对每个顶点组求连通分量。只有一个合法大区域时属于正常；有两个以上大区域时也
正常（例如裙子前片和后片）；只有**顶点数小于 Min Cluster Size 的非最大分量**
才报为孤立簇。所有分量都很小时，最大的那个被当作主区域，只报其余更小的。

### 逐顶点检查

- 零权重顶点（导出后不跟随骨骼）
- 影响数超过 Max Influences（只统计权重不低于 Min Weight 的影响；导出时按预设的 BLENDWEIGHT 布局截断）
- 权重和偏离 1（未归一化）
- 低于 Min Weight 的微小权重（仅计数提示，不算问题）

## 已知限制（使用前请阅读）

1. **孤立簇可能误报独立配件**。帽檐、眼镜、耳环这类独立小部件如果绑的是身体
   同一根骨骼，会因为“该骨骼在身体上已有大区域 + 配件是个小分量”而被报为
   孤立簇。面板报告只给簇数量和问题顶点总数，不显示每个簇的大小与位置；
   问题顶点会被选中，进入编辑模式即可查看具体位置。
2. **低模正常硬切也会被报**。两圈顶点的圆柱手腕直接 A/B 硬切，会报 8 条接缝。
   这确实是形变时会折断的地方，报告是合理的，但用户可能认为是“正常模型”。
3. **锁定顶点组也会被修改**。Blender 的 `lock_weight` 只拦 UI 手动编辑，Python
   API 照样写入。检测按钮不碰权重；平滑和清理会修改锁定组，执行时会在信息区
   报告 WARNING 级警告（不是模态弹窗）。
4. **只按拓扑连接判断邻接**。空间上紧贴但拓扑分离的两块网格互不影响，因此
   跨网格岛的权重跳变不会被接缝检查发现（这是有意为之，避免把独立部件算成接缝）。
5. **非流形边会被跳过**。三个或更多面共享的边无法判定边界性质，检测直接忽略。
6. **标记问题顶点会清空原有顶点选择**，并重置为只选中问题顶点。
7. 多对象、大量问题时报告面板最多显示 20 行，其余行数折叠提示。
8. 面板参数是场景级自定义属性，会随 `.blend` 保存；打开别人保存的工程会沿用
   其中的阈值设置。实测确认过（写入 0.75 保存后重新打开仍为 0.75）。
9. **接缝检测有明确的漏报边界**：零面积退化面、绕序翻转、非流形边、wire 边、
   开放边界边都不会被报，详见上文「接缝」的适用边界。这些边界都经过边界样本
   实测确认。另外，读入时丢弃 ≤1e-6 的权重，因此只剩微小权重的顶点会在清理
   时被跳过（它本来也没有有效的绑定）。
10. **Strength=1.0 的极端平滑会振荡**。平滑每轮用邻居平均替换目标顶点权重，
    Strength=1.0 时权重值会在接缝两侧顶点之间来回摆动（实测 3 轮与 20 轮的
    落点不同，例如某顶点 A 权重 0.667→0.5→0.713→0.5…）。建议保持默认 0.5。

| 样本 | 结果 |
|---|---|
| 共面两四边形、共享边两侧纯 A / 纯 B | 1 条接缝，2 个问题顶点 |
| 共面两四边形、共享边两侧含混合权重（L1 0.8） | 0 条接缝 |
| 共享骨骼且 L1 差 1.2（高于阈值） | 0 条接缝（共享骨骼分支独立生效） |
| 90° 折角 + 权重突变 | 0 条接缝（几何豁免） |
| 45° 折角（凸折角、正常绕序）+ 权重突变 | Smooth Angle 60° 时报 1 条；把 Smooth Angle 设为 44° 时豁免为 0 条 |
| 两个材质相邻 + 权重突变 | 0 条接缝（材质豁免） |
| 25 顶点主区域 + 3 顶点远处孤岛 | 1 个孤立簇，size 3 / main 25 |
| 两个 25 顶点分量 | 0 个孤立簇 |
| 8 段两圈圆柱、上下两圈 A/B 硬切 | 8 条接缝 |
| 10000 顶点 / 19800 边网格检测 | 约 0.1–0.3 秒（视负载，中位约 0.2 秒） |
| 100489 顶点 / 200344 边网格检测 | 约 1–4 秒（视负载，中位约 1.1–2.0 秒） |
| 20 轮强度 1.0 平滑（全顶点已归一化样本） | 权重和偏差 3e-8，无负权重（按原始 mesh 读取） |
| 20 轮强度 1.0 平滑（邻居含未归一化输入） | 目标顶点原始权重和为 1.0（偏差约 3e-8） |
| 连续清理两次 | 第一次 1 个顶点变化，第二次 0（幂等） |
| 清理阈值边界 `{a:1.0, b:0.01001}` | 第一次 1 个变化，第二次 0（幂等） |
| float32 阈值边界（归一化后恰为 0.01） | 第一次 1 个变化，第二次 0（幂等） |
| float32 ulp 边界（min_weight=0、10 个影响含 4 个 1e-6 级权重） | 第一次 1 个变化、第二次 0；写入后原始和与可见和一致，无不可见权重 |
| Min Weight=0 + 5 个 2.7e-6 权重 | 第一次剪到读层可见，第二次 0（幂等） |
| min_weight=1.9e-6 且权重 1.2e-6 | 被移除（用户阈值不被读层 epsilon 吞掉） |
| min_weight=0.01 且权重 0.0101005 | 归一化后低于阈值，被移除；无 `[阈值-1e-6, 阈值)` 残留 |
| 平滑写回后读回 | 原始和与可见和都为 1.0（无不可见权重残留） |
| 重新检测到 0 个问题 | 上一次的顶点标记被清空 |

性能说明：检测与平滑需要遍历全网格收集权重与邻接，清理只遍历权重，因此总耗时
随网格大小近似线性（实测 10000 顶点约 0.2 秒、100489 顶点约 2 秒），属于用户
主动点击一次的量级。只有写回部分与问题数量相关，问题少时写回开销可忽略。
