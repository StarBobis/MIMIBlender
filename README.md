# MIMIBlender

- 配套 Blender 版本：**Blender 5.2 及以上**
- 最新版下载：https://github.com/StarBobis/MIMIBlender/releases/latest
- 手工替换贴图时，保留生成目录 `Textures` 中原有的文件名。重新生成 Mod 时，默认贴图只会补齐缺失文件。蓝图中显式指定的贴图按节点设置更新。

---

- Requires **Blender 5.2+**
- Latest release: https://github.com/StarBobis/MIMIBlender/releases/latest
- To replace a texture manually, keep its existing filename in the generated `Textures` folder. Regenerating the Mod fills in missing default textures. Explicit blueprint texture assignments update their output as configured.
